# Overview
A music player written in Kotlin for Android version 11 and above.

## Highlights
- It has an audio visualizer
- The pitch and speed of music can be changed
- The UI's colors can be customised
- The overlay allows you to switch the playing queued songs from anywhere on your phone

## Installation
To install, download the apk from releases and install it on an android phone, alternatively you can git clone this repo and build it with `./gradlew`
